## 引言
TyxonQ编译引擎为量子电路提供统一的编译接口，支持三种核心编译模式：原生编译器（NativeCompiler）、Qiskit编译器（QiskitCompiler）和Guodun编译器（GuodunCompiler）。原生编译器专注于内部优化和快速执行，通过构建可定制的编译流水线对电路进行优化；Qiskit编译器用于与IBM量子硬件集成，利用Qiskit的transpile功能进行硬件适配和门集映射；Guodun编译器专为国盾量子硬件平台设计，支持QCIS格式编译和原生脉冲编程。本技术文档详细阐述三种编译引擎的实现机制、架构设计及使用方式。

## 原生编译器实现机制
原生编译器（`NativeCompiler`）是TyxonQ的核心编译组件，负责执行电路优化和编译流水线。其主要功能包括构建编译计划、执行优化阶段以及根据输出参数生成不同格式的电路表示。

## Qiskit编译器实现机制

## Guodun编译器实现机制
Guodun编译器（`GuodunCompiler`）是专门为国盾量子硬件平台设计的编译引擎，将TyxonQ电路转换为平台使用的QCIS格式。它支持完整的门级QCIS操作和原生脉冲编程功能。

### 门级QCIS编译
Guodun编译器通过以下步骤将TyxonQ电路转换为QCIS：

```mermaid
flowchart TD
A[TyxonQ Circuit] --> B[Qiskit基础门降阶]
B --> C[QASM2生成]
C --> D[门级QCIS转换]
D --> E[物理比特映射]
E --> F[QCIS输出]
```

### 支持的QCIS指令
Guodun编译器支持以下QCIS指令：
- **X**: X门操作
- **H**: Hadamard门操作  
- **RZ**: RZ旋转门操作
- **CZ**: CZ纠缠门操作
- **M**: 测量操作

### 原生脉冲编程支持
Guodun编译器还提供原生脉冲编程功能，支持以下脉冲指令：
- **PXY/PZ/PZ0**: 脉冲控制指令
- **G**: 耦合器控制指令
- **I**: 延迟指令
- **B**: 绑定指令
- **RZ**: 虚拟Z门指令

## 编译流水线构建与优化阶段
原生编译器通过`build_plan`函数构建编译流水线，该流水线由多个优化阶段组成，包括重写（rewrite）、简化（simplify）和调度（scheduling）等。

### 编译流水线构建

## API使用与回退机制
用户可以通过`compile()` API切换不同的编译引擎。系统支持智能回退机制，当指定的编译引擎不可用时，会自动选择合适的替代方案。

### API调用示例
```python
# 使用原生编译器
result = compile(circuit, compile_engine="native", output="ir")

# 使用Qiskit编译器
result = compile(circuit, compile_engine="qiskit", output="qiskit")

# 使用Guodun编译器
result = compile(circuit, compile_engine="guodun", output="qcis", 
                options={"physical_qubits": [0, 1]})

# 使用默认编译器（原生）
result = compile(circuit)
```

### 回退机制
当指定的编译引擎不可用时，系统会按以下顺序尝试回退：
1. 如果请求的引擎不可用，尝试原生编译器
2. 如果原生编译器失败，尝试其他可用引擎
3. 最终回退到原生编译器作为最后选择

```mermaid
sequenceDiagram
participant User as "用户"
participant API as "compile API"
participant Native as "原生编译器"
participant Qiskit as "Qiskit编译器"
participant Guodun as "Guodun编译器"
User->>API : 调用compile(engine="guodun")
API->>Guodun : 尝试调用Guodun编译器
alt Guodun可用
Guodun-->>API : 返回编译结果
else Guodun不可用
API->>Native : 回退到原生编译器
Native-->>API : 返回编译结果
end
API-->>User : 返回编译结果
```

## 结论
TyxonQ编译引擎提供了灵活且强大的编译能力，支持原生编译器、Qiskit编译器和Guodun编译器三种模式。原生编译器通过可定制的编译流水线实现了高效的电路优化，适用于内部优化和快速执行；Qiskit编译器则通过与Qiskit的集成，实现了与IBM量子硬件的无缝对接；Guodun编译器专为国盾量子硬件平台设计，提供完整的QCIS格式支持和原生脉冲编程能力。用户可以根据具体需求选择合适的编译引擎，并通过统一的API进行调用。当指定的编译引擎不可用时，系统会自动回退到其他可用引擎，确保编译过程的可靠性和灵活性。

新增的Guodun编译器引擎显著增强了TyxonQ在国产量子硬件平台上的支持能力，特别是其完整的脉冲编程功能和严格的安全验证机制，为用户提供了从门级电路到原生脉冲的完整编译链路。
