## 简介
本章节面向量子计算初学者与有经验的开发者，系统阐述 TyxonQ 的核心概念与抽象设计。内容覆盖：
- 量子电路（Circuit）的中间表示（IR）、量子门操作、测量与状态初始化
- 编译器的工作流程与优势
- 链式 API 的设计模式与调用流程
- 数值后端（ArrayBackend）的统一接口与选择策略（NumPy、PyTorch、CuPyNumeric）
- 设备抽象层对模拟器与真实硬件的统一调度
- 丰富的代码示例路径，帮助读者快速上手并深入理解

## 项目结构
TyxonQ 采用分层模块化设计，核心 IR、编译器、设备抽象与数值后端解耦清晰：
- 核心 IR：Circuit/Hamiltonian/Pulse 等数据结构位于 core/ir
- 编译器：gate/pulse 编译管线在 compiler/ 下，支持多平台输出
- 设备层：devices/base 提供统一运行入口，simulators/hardware 分别实现本地仿真与云端/真机驱动
- 数值后端：numerics 提供 ArrayBackend 协议与后端切换能力
- 顶层入口：tyxonq.__init__ 暴露便捷 API（如 set_backend、device/postprocessing/compile 默认值）

## 核心组件
- 量子电路 IR（Circuit）：以 num_qubits 与 ops/instructions 描述电路，支持元数据、初始态、噪声配置、脉冲编译开关等
- 编译器（Compiler API）：统一入口 compile()，按 platform/output 分派到不同平台或脉冲编译器，支持分解、路由、优化、光锥简化
- 设备抽象（Device Layer）：统一 run()/expval()，自动注入噪声、处理 shots、归一化结果格式，屏蔽模拟器与硬件差异
- 数值后端（ArrayBackend）：统一数组/张量接口，支持 NumPy/PyTorch/CuPyNumeric 切换，提供 vmap 向量化与自动微分桥接
- 顶层便捷 API：set_backend/get_backend/set_dtype、device/postprocessing/compile 全局默认值管理

## 架构总览
TyxonQ 将“线路构建 → 编译 → 执行 → 后处理”解耦为独立阶段，通过类型化参数与统一协议串联：
- 线路构建：Circuit 对象累积 ops/instructions，支持 compose/remap/extended 等操作
- 编译阶段：compile() 根据 platform/output 选择 gate/pulse 编译器，执行分解、路由、优化、简化
- 执行阶段：devices/base.run() 解析 provider/device，选择模拟器或硬件驱动，注入噪声与 shots，返回统一任务对象
- 后处理：postprocessing 选项控制读误校正、期望值聚合等

### 编译器（Compiler）设计与工作流程
- 统一入口：compile(circuit, platform, output, basis_gates, decompose, route, optimize, simplify, device_rule, options)
- 平台分派：
  - tyxonq：核心 gate 编译器，输出 ir/qasm2/qasm3/qiskit
  - pulse：脉冲级编译，生成 TQASM/OpenQASM3 或 native pulse_ir
  - lqcloud/guodun：硬件平台方言
- 智能推断：检测到脉冲操作或 use_pulse() 时自动启用 pulse 编译
- 优化步骤：分解 matchgate/旋转、相邻门合并、恒等剪枝、光锥简化、路由（耦合图）

## 性能考量
- 模拟器选择：
  - statevector：适合中小规模精确模拟，内存 O(2^n)
  - matrix_product_state（MPS）：低纠缠态高效近似，内存 O(nχ)
  - density_matrix：支持噪声与混合态，开销更高
- 编译器优化：
  - 分解与路由：减少原生门不匹配导致的额外开销
  - 光锥简化：裁剪不影响测量的算符，降低深度
- 数值后端：
  - NumPy：轻量、稳定，适合原型与小规模
  - PyTorch：GPU 加速、自动微分、JIT，适合 VQA 训练
  - CuPyNumeric：GPU 加速的 NumPy-like，适合大规模态矢运算
- 批处理与 shots：
  - 批量电路提交保持顺序，shots 可为标量或对齐列表
  - shots==0 走解析期望值路径，避免采样噪声

## 故障排查指南
- 运行时错误：
  - 未提供 circuit 或 source：devices.base.run 会抛出 ValueError
  - 不支持的 provider/device：resolve_driver 抛出 ValueError
  - 脉冲编译缺少 device_params：自动补足默认测试参数并发出警告
- 结果异常：
  - 异步任务超时：get_task_details 发出 RuntimeWarning，建议增大 timeout
  - 噪声配置未生效：确认 use_noise/noise 注入逻辑与设备类型
- 调试建议：
  - 使用 gate_summary/count_flop 检查电路规模
  - 使用 to_json_obj 序列化电路便于复现
  - 切换后端验证一致性（NumPy vs PyTorch）
