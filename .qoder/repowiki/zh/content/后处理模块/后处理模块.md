## 简介
后处理模块负责将量子设备或仿真器返回的原始结果转换为可靠的物理量。当前版本通过统一的 apply_postprocessing 路由，将误差缓解、期望值聚合、读出校正等功能集成到一致的接口中；同时提供经典阴影、度量计算、IO 转换和噪声分析等工具，便于在设备执行后快速进行高质量的数据分析。

## 核心组件
- 统一路由：apply_postprocessing 根据 options["method"] 分发到具体实现
- 误差缓解：ZNE、DD、RC 的轻量占位实现，便于后续扩展
- 经典阴影：随机 Pauli 基生成与 Z 期望估计
- 读出校正：单量子比特校准矩阵与 inverse/square 两种反演方法
- 度量计算：归一化、KL 散度、对角可观测期望值
- IO 工具：CSV 往返、计数向量转换、直方图绘制等
- 噪声分析：比特翻转与去极化通道在计数层面的近似

## 统一后处理入口
apply_postprocessing 是后处理的统一入口，支持以下 method：
- readout_mitigation：使用 ReadoutMit 对计数进行读出误差校正，返回 raw_counts/mitigated_counts/mitigation_time_ms
- expval_pauli_term：计算单个 Pauli-Z 项的期望值
- expval_pauli_terms：批量计算多个 Pauli-Z 项的期望值
- expval_pauli_sum：聚合哈密顿量期望值，支持可选的读出校正与解析路径（当 counts 为空但存在 expectations/probabilities/statevector 时）

关键行为
- 自动推断 shots：优先 metadata.shots，否则从 counts 求和推断
- 解析路径：当 counts 为空时，尝试从 result_meta 恢复 expectations/probabilities/statevector，并使用概率或态矢量计算精确期望值
- 失败保护：异常被捕获并返回部分结果，避免上层抛出

```mermaid

GetMethod --> Check{"是否指定方法?"}
Check --> |否| ReturnNone["返回 {method: None, result: None}"]

E3 --> End
```

## 误差缓解技术
当前为轻量占位实现，便于后续接入完整库（如 mitiq）。
- apply_zne：多次执行 executor 并取平均，模拟零噪声外推的平均步骤
- apply_dd：多次执行 executor 并平均计数或数值结果，不修改电路
- apply_rc：多次执行 executor 并平均，返回平均值与电路列表

这些函数可作为未来扩展的骨架，当前主要用于验证流程与测试。

## 经典阴影方法
经典阴影用于以少量测量估计量子态信息。
- random_pauli_basis/random_pauli_bases：生成随机 Pauli 基（含 I/X/Y/Z 或 X/Y/Z）
- estimate_z_from_counts：基于 bitstring 计数估计单量子比特 Z 期望
- estimate_expectation_pauli_product：基于多 shot 的基与结果估计 Pauli 乘积期望

## 读出校正
ReadoutMit 支持单量子比特校准矩阵，并通过 Kronecker 积构建多量子比特校准矩阵。
- set_single_qubit_cals：设置每个量子比特的 2x2 校准矩阵
- mitigate_probability：支持 inverse（伪逆）与 constrained least squares（单纯形约束）两种方法
- apply_readout_mitigation：将计数转为概率向量，应用校正后再转回计数

## 后处理流程配置
Circuit 在执行完成后会调用 apply_postprocessing，并将 postprocessing 字段附加到结果中。用户可通过 Circuit 的后处理选项（_post_opts）指定 method 及参数。

```mermaid
sequenceDiagram
participant C as Circuit
participant P as apply_postprocessing
participant R as ReadoutMit
participant E as counts_expval
C->>P : 传入 result + options
alt method=readout_mitigation
P->>R : 设置校准矩阵并校正计数
R-->>P : 返回校正后的计数
else method=expval_pauli_term/terms/sum
P->>E : 计算期望值必要时走解析路径
E-->>P : 返回期望值/能量
end
P-->>C : 返回 {method, result}
```

## 后处理策略建议
- 高读出误差环境：优先使用 readout_mitigation，确保提供准确的单量子比特校准矩阵
- 相干噪声环境：结合 DD 占位实现评估噪声抑制效果，后续可接入更完整的动态解耦策略
- 非马尔可夫噪声环境：使用 ZNE 占位框架，逐步接入缩放与拟合流程
- 资源受限环境：采用经典阴影方法，用少量测量估计有用信息
- 需要快速基线：利用噪声分析适配器在计数层面近似噪声，辅助对比不同策略
