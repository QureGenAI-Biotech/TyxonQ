### 两层编译器架构
- 定义：v1.4 重构后的编译器设计：设备无关的 `gate_compiler` 核心负责组装类型化步骤流水线（normalize → decompose → route → optimize → simplify），各硬件 `platforms/*` 方言层（tyxonq/lqcloud/guodun）仅做方言翻译与导出，避免重复实现编译逻辑。
- 别名：gate_compiler、Two-Layer Compiler Architecture

### CompileStep
- 定义：替代原 `Pass` 协议的编译步骤抽象，每个步骤类定义 `apply(circuit, opts)` 方法，由 `build_compile_steps()` 装配、`apply_steps()` 顺序执行。去除了过度 IT 化的 `*Pass` 后缀命名。
- 别名：步骤协议、step

### DeviceRule
- 定义：描述目标硬件拓扑与运行约束的设备规则对象，包含耦合图、门集、shot 预算等元数据。编译期由 platform 构造，运行期经 `topology.get_device_rule` 发现（带 1 天 TTL 缓存），失败时优雅退回直译。
- 别名：设备规则、device rule

### 链式 API
- 定义：TyxonQ 的主编程模型：`Circuit.compile().device(...).postprocessing(...).run()`，将编译、设备绑定、后处理、执行串联为单一流畅接口。
- 别名：chain API、Chain API

### 双路径执行
- 定义：同一 Circuit 可同时走两条执行路径：(a) 经典数值路径（statevector/density_matrix/mps 模拟器，精确期望值）与 (b) 真实/模拟量子路径（shots/noise，counts-first 语义），共享相同的 Hamiltonian、测量分组与 shot 规划语义。
- 别名：dual paths、双执行路径

### QM/MM 根音主线
- 定义：项目长期演进主线之一：将量子力学（QM）与分子力学（MM）结合，通过 i-PI/MDI 接口驱动分子动力学模拟，是 HANDOFF 中保留的核心方向，与编译器重构并行推进。
- 别名：QM/MM、量子-经典混合

### Skill（Agent Skill）
- 定义：面向 AI Agent 的可执行知识单元，存放于 `.qoder/skills/`，包含可直接运行的代码片段（而非伪代码），调用 TyxonQ 已有原语（如 `gate_summary()`、`routing.py` 中的纯函数）对 ansatz 进行硬件友好度快速反馈。
- 别名：agent skill、技能

### MCP（Model Context Protocol）
- 定义：AI Agent 与 TyxonQ 的集成协议，使远端/第三方 Agent 可通过结构化工具程序化查询框架能力。本项目通过 OpenQuantum 项目提供 MCP 工具集成，但对话中明确其为可选方案（IDE 内 Agent 场景下视为负担）。
- 别名：Model Context Protocol、OpenQuantum

### Ansatz 硬件友好度
- 定义：评估量子电路（ansatz）在特定硬件拓扑上的可执行性指标，包括双比特门数、拓扑冲突数、SWAP 下界、是否跨连通块等，通过调用 gate_compiler 中的纯函数快速反馈，用于指导 VQE/SQD 等算法的 ansatz 编写。
- 别名：hardware-friendly ansatz、ansatz 检查

### Fsim 门分解
- 定义：物理学家指导下的两比特门分解实践：fsim 门通常分解为 iswap + cphase，是 compile 架构升级过程中 AI 辅助实现的典型门级优化案例。
- 别名：fsim decomposition、fsim→iswap+cphase
