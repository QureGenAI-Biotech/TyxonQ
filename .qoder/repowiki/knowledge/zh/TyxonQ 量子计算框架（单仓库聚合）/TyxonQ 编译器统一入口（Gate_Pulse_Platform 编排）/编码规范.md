- 所有编译入口返回统一的 TypedDict 结果结构（CompileResult / PulseCompileResult），包含 circuit、compiled_source、metadata 三个字段。
- 平台选择通过字符串 platform 参数分发，并在入口处归一化为小写（default/native→tyxonq，qiskit→tyxonq）。
- 编译产物源码通过写入 `circuit._compiled_source` 缓存，供后续重复访问复用。
- 各平台编译器对外暴露 `.compile(circuit, decompose=, route=, device_rule=, options=)` 签名，由 api 层统一转发类型化参数。
