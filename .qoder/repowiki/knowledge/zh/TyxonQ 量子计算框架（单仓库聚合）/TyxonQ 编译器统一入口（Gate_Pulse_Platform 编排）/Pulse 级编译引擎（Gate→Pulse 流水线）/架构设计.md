模块以 `PulseCompiler`（`native/pulse_compiler.py`）为编排入口，按固定流水线串联三个 Pass：`GateToPulsePass` → 可选 `PulseLoweringPass` → `PulseSchedulingPass`，每个 Pass 通过统一的 `execute_plan(circuit, **options)` 接口接收/返回不可变 `Circuit`（使用 `dataclasses.replace` 重建），并通过 `circuit.metadata` 在 Pass 间传递 `pulse_library`、`pulse_device_params`、`pulse_calibrations`、`pulse_schedule` 等上下文。

- `native/gate_to_pulse.py`：实现单/双量子比特门（X/Y/Z/H/CX/CZ/iSWAP/SWAP）到 DRAG/Gaussian/Constant 波形的物理分解，优先查找 `DefcalLibrary` 或元数据中的用户校准，否则回退默认分解；同时生成 `virtual_z` 操作并在末尾合并相邻相位帧更新。
- `native/pulse_lowering.py`：将符号化的 `("pulse", qubit, key, params)` 展开为自包含的 `("pulse_inline", qubit, waveform_dict, params)`，波形对象通过 `qasm_name()/to_args()` 或 dataclass 转为字典。
- `native/pulse_scheduling.py`：基于 qubit 可用性时间线进行并行调度，输出 `pulse_schedule` 与总时长并写回元数据。
- `defcal_library.py`：提供 `CalibrationData` dataclass 与 `DefcalLibrary` 存储/查询/JSON 持久化，键为 `(gate, qubits_tuple)`，支持按 gate/qubit 过滤。
- `serialization.py`：提供 JSON/Pickle 两种格式对编译后的 Circuit 做序列化，JSON 路径要求已内联波形。
- `__init__.py` 通过 `__getattr__` 延迟导入避免循环依赖，对外暴露 `PulseCompiler`、`DefcalLibrary` 及序列化函数。
- 依赖方向单向：顶层包 → `native/` 子模块 → `tyxonq.core.ir.Circuit` 与 `tyxonq.waveforms`，不反向依赖上层。
