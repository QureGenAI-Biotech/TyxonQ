模块以 `compiler.py` 中的 `GateCompiler.compile` 为统一入口，接收 `basis_gates/decompose/route/optimize/simplify/device_rule/options` 等参数，调用 `steps.build_compile_steps` 生成 `CompileStep` 列表，再由 `apply_steps` 顺序执行。

- 规格定义层：`specs.py` 用 dataclass 描述 `DecomposeSpec`、`RoutingSpec`，并提供 `coerce_*` 将 bool/None 归一化为 spec 实例，实现“一键开关 + 细粒度配置”的统一接口。
- 步骤装配与执行层：`steps.py` 固定装配顺序为 AutoMeasure → GatesTransform → MatchgateDecompose/RotationsDecompose → Routing → MergePrune → LightconeSimplify；每个子步骤通过延迟 import 避免默认路径引入额外依赖。
- 阶段子包 `stages/`：按职责划分为 `decompose/`（matchgate、rotations）、`rewrite/`（auto_measure、gates_transform、merge_prune）、`layout/`（routing，委托 qiskit.transpile）、`simplify/`（lightcone），每个类实现 `apply(circuit, **opts)` 协议。
- 输出层：`exporters/` 提供纯 Python 的 `GateQASM2Exporter` / `GateQASM3Exporter`；`interop/` 提供与 Qiskit 的双向转换及 MPO 张量网络导入。
- 依赖方向：`compiler` → `steps` → `stages/*`；`compiler` 仅在需要时按需导入 exporters/interop，保持核心装配零额外依赖。
- 顶层 `__init__.py` 仅暴露 `GateCompiler`、`DecomposeSpec`、`RoutingSpec`、`build_compile_steps`、`apply_steps` 作为公共 API。
