本模块是一组以 pytest 编写的 smoke/integration 测试，每个 `test_example_*.py` 对应一个 `examples/` 下的示例脚本。测试通过 `importlib.util.spec_from_file_location` 动态加载目标示例模块（路径形如 `Path(__file__).parent.parent / "examples" / f"{name}.py"`），再调用其暴露的函数或执行 `main()` 来验证行为。测试按功能域组织：VQE 系列（`vqe_extra`、`vqe_noisyopt`、`vqe_parallel_pmap`、`vqe_shot_noise`、`vqetfim_benchmark`、`vqe_h2o_benchmark`）、编译器相关（`circuit_compiler`、`compiler_lightcone_optimization`）、混合量子-经典训练（`hybrid_quantum_classical_training`）、梯度与自动微分（`autograd_vs_counts`、`parameter_shift`、`jacobian_cal`、`sample_value_gradient`、`quantum_natural_gradient_optimization`）、采样与噪声（`sample_benchmark`、`noise_controls_demo`、`readout_mitigation`）、云 API（`cloud_api_devices`、`cloud_api_task`）以及基础链式 API 演示等。对于耗时或依赖外部资源的用例，使用 `@pytest.mark.slow` 标记并通过减小参数规模或重定向 stdout 控制运行开销；对可选依赖缺失的情况统一捕获 `ImportError` 并调用 `pytest.skip` 跳过。
