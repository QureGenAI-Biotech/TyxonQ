- 每个 provider 驱动以独立子包形式组织，统一暴露 `run`、`get_task_details`、`remove_task`、`list_devices` 四个函数，并通过 `__all__` 显式导出。
- 任务句柄使用 `@dataclass` 定义（如 `LQCloudTask`、`GuodunTask`、`QuafuTask`），包含 `id`、`device`、`status`、`async_result` 等统一字段以便上层轮询。
- Token 解析遵循固定优先级：显式 `token=` 参数 → `set_token(provider=...)` → 专用环境变量（如 `TYXONQ_LQCLOUD_API_KEY`、`TYXONQ_GUODUN_TOKEN`），缺失时抛出含使用说明的 `RuntimeError`。
- 外部 SDK 通过局部函数内的 `try: import ... except ImportError` 延迟加载，并在版本不匹配时给出明确的 `pip install 'tyxonq[...]'` 提示。
- 设备名统一采用 `<provider>::<device>` 格式，驱动内部通过 `device.split('::')[-1]` 剥离前缀后再传给上游 SDK。
- 结果归一化为包含 `result`、`result_meta`、`uni_status`、`error` 四键的字典结构，由各个 driver 将平台特定响应映射为该统一形状。
