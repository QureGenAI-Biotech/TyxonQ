模块以 provider 子目录划分不同云厂商的驱动实现（guodun、lqcloud、quafu、qcos、tyxonq、ibm），每个子包暴露一致的 `run` / `get_task_details` / `remove_task` / `list_devices` 函数契约；顶层 `config.py` 维护全局 token 存储（内存 `_TOKENS`）、默认 provider/device 以及各 provider 的 ENDPOINTS；`topology.py` 作为跨 provider 的统一入口，通过 `fetch_topology` 分派到 `compiler.platforms.<provider>.get_topology`，并以「会话内内存缓存 + 磁盘 JSON 文件（`.topology_cache.json`）」两级结构实现带 `max_age_days` TTL 的设备耦合图缓存，抓取失败时降级沿用过期缓存或返回空规则以保证编译不中断。依赖方向单向：各 driver → `..config.get_token`，`topology` → `compiler.platforms.*`，driver 之间互不引用。
