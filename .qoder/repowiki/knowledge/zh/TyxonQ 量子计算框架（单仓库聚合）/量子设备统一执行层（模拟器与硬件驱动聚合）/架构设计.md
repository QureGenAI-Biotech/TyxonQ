本模块以 `base.py` 中的 `Device` Protocol、`DeviceRule` / `RunResult` TypedDict 以及 `DeviceTask` 数据类作为跨子模块的统一契约：`hardware/` 下的各云平台驱动与 `simulators/` 下的三种模拟器引擎均按该契约实现，由 `resolve_driver(provider, device)` 在运行时根据 provider 字符串动态导入对应驱动模块（simulator → simulators.driver；tyxonq/ibm/qcos/quafu/lqcloud/guodun → hardware.<prov>.driver）。`run()` 和 `expval()` 是对外入口，负责解析默认 provider/device、注入噪声配置、对真机丢弃模拟器专属参数、并将任意驱动返回的句柄包装为统一的 `DeviceTask`，再由 `get_task_details()` 轮询并归一化结果 schema（result/result_meta/metadata/expectations/probabilities）。拓扑信息集中在 `hardware/topology.py` 发现并缓存，供编译器路由使用；`device_descriptor()` 提供从名称到 {provider, device} 的解析，使上层电路 API 无需感知后端差异。
