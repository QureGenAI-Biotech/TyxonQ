- 每个计算方法（fci/ccsd/dft/mp2/casscf）统一构造包含 method、molecule_data、method_options、classical_device、verbose 的 task_spec，再调用 `cloud_client.submit_classical_calculation` 并返回 `result['energy']`。
- 服务端 `cpu_chem.compute` 与 `gpu_chem.compute` 共享相同的输入解析流程：先解析 method_list（字符串或列表）、构建分子、运行一次 HF 并导出 chkfile 供后续方法复用。
- GPU 后端通过 try/except 导入 `gpu4pyscf`，并以 `gpu_available` 标志配合 `auto` 设备策略在 `app._route_backend` 中实现运行时回退到 CPU 后端。
- 客户端与服务端之间通过 JSON 字典传递任务，数值数组统一转为 Python list 后再序列化，避免 numpy 对象直接入 JSON。
