本模块以 `src/tyxonq/applications/chem` 为核心，按职责拆分为四个子包并通过共享的 TyxonQ 电路与波函数类型进行协作：
- `algorithms/`（VQE、LUCJ、SQD）负责电子结构求解，产出波函数供其他子包消费；
- `dynamics/` 基于这些波函数与 renormalizer 运行时实现时间演化，复用同一套哈密顿量构建方式；
- `classical_chem_cloud/` 通过 HTTP API 暴露 PySCF/FastAPI 后端，与量子算法形成互补（经典方法 vs 量子方法）；
- `interfaces/` 将扫描器封装为 ASE/i-PI/OpenMM/MDI 可识别的势能面，使量子/经典结果均可嵌入分子动力学环境。
四者共同依赖 `molecule.py`、`hamiltonian_builders.py`、`constants.py` 等基础构件，构成从分子建模→电子结构→动力学→外部生态接口的完整链路。
