模块按职责划分为六个文件：`topology.py` 提供轨道数/层数校验、拓扑名归一化、alpha/beta qubit 编号映射以及 `square/hex/linear` 三种拓扑下的相互作用 pair 生成；`linalg.py` 封装 anti-Hermitian/unitary/real-symmetric 矩阵与实参数向量之间的双向编解码、Givens 相邻旋转分解及两模 Fock 提升；`parameters.py` 定义 matrix LUCJ 的参数字典 schema（`orbital_rotations`、`diag_coulomb_mats`、可选 `final_orbital_rotation`），并提供 shape 查询、计数与 unitary/对称性校验；`circuit_builder.py` 暴露 `LUCJ` 类与 `build_lucj_circuit`，按固定顺序 `RHF参考态 → U† → diagonal Coulomb → U` 把参数翻译为 TyxonQ `Circuit`，并在 metadata 中记录逻辑门索引以便测试；`conversion.py` 将压缩 DF 结果 (`DoubleFactorizationResult`) 裁剪到指定层数后包装成 normalized 参数字典；`initialization.py` 作为对外入口，串联 `double_factorize_t2` → `factors_to_lucj_parameters` 从 CCSD t1/t2 生成初始参数。依赖方向单向：`circuit_builder` → `parameters` + `topology` + `linalg`，`initialization` → `conversion` → `double_factorization` + `parameters`，顶层 `__init__.py` 仅做 re-export。
