- 文档源文件按主题分目录组织（getting_started、user_guide、quantum_chemistry、libraries、cloud_services、tutorials、examples、api、developer_guide、technical_references），每个子目录以 index.rst 作为入口 toctree。
- API 参考统一通过 autosummary + autodoc 自动生成，stub 文件位于 source/api/*/index.rst，对应 locale 下同名 .po 用于翻译。
- 多语言翻译遵循 Sphinx gettext 规范，source 中的文本经 make gettext 提取后同步到 locale/zh_CN/LC_MESSAGES/ 下相同路径的 .po 文件。
- 构建流程通过 Makefile 目标与 build_docs.sh 脚本双入口管理，所有语言变体（en/zh/ja）共享同一套源文件与构建目标。
- 数学公式使用 LaTeX 语法并通过 MathJax 渲染，图表使用 Mermaid 块并通过 sphinxcontrib-mermaid 转换为 SVG。
