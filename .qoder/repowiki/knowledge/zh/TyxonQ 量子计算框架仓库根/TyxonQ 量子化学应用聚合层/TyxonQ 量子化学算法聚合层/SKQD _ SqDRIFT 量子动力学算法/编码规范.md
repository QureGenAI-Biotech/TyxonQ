- 所有公开数值入口在开头调用 `operator.index()` 把参数转为 Python int，并对范围、正性、形状做显式 `ValueError` 校验。
- 生成的线路在 `metadata['skqd']` 中写入 circuit_id/k/time 等诊断字段，便于下游反查来源。
- 可持久化对象使用带版本号的 JSON schema（如 `tyxonq.skqd.ensemble.v1`）而非 pickle，并通过 `__skqd_array__` 标记复数 numpy 数组。
- 组合型结果通过 `dataclasses.dataclass` 暴露（`SKQDResult`、`GaussianFit`、`FermionicGroup`、`CircuitRecord`），并在 `__post_init__` 中执行一致性检查。
- Hamiltonian 相关计算先经 `validate_integrals(h1e, eri, norb, nelec)` 归一化为内部 `(h, g, n, nelec)` 形式再进入算法主体。
