模块按职责拆分为六个平级文件，通过 `__init__.py` 统一暴露高层 API：
- `circuit_builder.py`：构造 Slater 参考态与二阶 Trotter-Krylov 演化线路（H2/2-H1-H2/2），依赖 `chem_libs.fermionic_circuits` 的低层门原语。
- `qdrift.py`：实现 SqDRIFT，对 FermionOperator 按 active/spectator 模式分组、JW 变换后抽样 Pauli 项，复用 `reference_circuit` 与 `validate_schedule`。
- `ensemble.py`：定义 `CircuitRecord` / `SKQDEnsemble` 数据结构，提供跨进程 JSON 序列化（schema `tyxonq.skqd.ensemble.v1`）、`merge_skqd_samples` 撤销 mode_permutation/measurement_map 并汇总 counts，以及本地 statevector 采样。
- `driver.py`：将 ensemble 样本接入既有 `..sqd.run_sqd_fermion`，封装为 `SKQDResult`，仅在最外层加一次 energy_offset。
- `gaussian.py`：用 L-BFGS-B 拟合固定深度的 Givens 网络逼近单粒子演化，供 Trotter 子步替换精确旋转。
- `basis.py` / `layout.py`：自然轨道基变换与模式排序优化，被 qdrift 的 layout 路径调用。
依赖方向单向向外：本模块依赖 `tyxonq.core.ir.circuit.Circuit` 与 `..chem_libs.*`，并通过 `..sqd` 回接经典 SCI 求解器；不反向依赖上层应用。
