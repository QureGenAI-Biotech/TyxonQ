模块以 `driver.py` 中的 `EWF` 类为唯一对外编排入口：`kernel()` 依次调用 `fragmentation.IAOFragmentation` → `bath.build_bath` → `cluster.build_cluster` → `solver.solve_cluster`，再按 `energy_functional`（`wf` / `dmet` / `density`）走不同能量路径，并可选地经 `gradient.nuclear_gradient` 计算核梯度。

内部按职责分层：
- `types.py`：用 `@dataclass(frozen=True)` 定义跨层共享的不可变数据契约（`BathData`、`Cluster`、`SolverResult`、`FragmentResult`、`EWFResult`），并通过 `SpinArray = np.ndarray | tuple[np.ndarray, np.ndarray]` 统一 RHF/UHF 双自旋语义；`Cluster.is_unrestricted` 等属性在访问处自动展开。
- `bath.py`：提供 `DMETBath`、`MP2BNO` 两种浴构造及 `build_bath` 工厂，依赖 `linalg` 做 AO-metric 正交归一化。
- `cluster.py`：把 bath 投影到 active/frozen 轨道并组装 Fock/h_eff/ERI。
- `solver.py`：把 `Cluster` 包装成 PySCF `RHF/UHF` 对象后调用 `pyscf.cc.RCCSD` / `pyscf.fci`，返回 `SolverResult`。
- `energy.py`：纯函数式能量重构（wavefunction 投影、democratic DMET、cumulant RDM2）。
- `density.py` / `gradient.py`：仅在 `energy_functional='density'` 时延迟导入，避免不必要的依赖。
- `linalg.py`：底层线性代数原语（`hstack`、`metric_overlap`、`canonicalize_subspace`、`eigh` 等）。
- `fragmentation.py`：IAO 原子分片上下文管理器。

依赖方向单向：`driver → {bath, cluster, solver, energy, fragmentation} → types/linalg`；`__init__.py` 仅做白名单式 re-export，形成稳定的公开 API 边界。
