- 跨层数据结构统一使用 `@dataclass(frozen=True)` 定义，并通过 `field(default_factory=dict)` 暴露 `diagnostics` 字典，便于追加诊断信息而不破坏不可变性。
- RHF 与 UHF 的双自旋语义通过 `SpinArray = np.ndarray | tuple[np.ndarray, np.ndarray]` 类型别名表达，所有读取处用 `_is_spin_pair` 或 `is_unrestricted` 属性进行分支处理。
- 公共选项字典采用「默认值 + 白名单校验」模式：先 `defaults.copy()`，再用 `set(supplied) - set(defaults)` 检测未知键并抛出 `TypeError`/`ValueError`。
- 对输入对象（mean-field、fragment、cluster）在进入主逻辑前集中做形状、收敛性、实数性校验，失败时抛出带上下文的 `TypeError`/`ValueError`/`RuntimeError`。
- 可选重型子模块（`density`、`gradient`）在 `EWF.kernel` 中按需 `from .xxx import ...` 延迟导入，避免非相关功能路径承担额外依赖。
- 公开 API 集中在 `__init__.py` 中显式 re-export，未列出的符号不对外暴露，形成稳定的包级契约。
